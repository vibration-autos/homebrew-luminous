# Luminous Homebrew Tap

Homebrew tap for [luminous-rs](https://github.com/vibration-autos/luminous-rs).

## Installation

```bash
brew tap vibration-autos/luminous
brew install lum
```

## Update

```bash
brew update
brew upgrade lum
```

## Uninstall

```bash
brew uninstall lum
brew untap vibration-autos/luminous
```
